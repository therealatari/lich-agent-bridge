# Agent entry point

For work involving GemStone IV, Lich scripts, game integration, or project
planning, read `wiki/Home.md` and the pages it routes to
for that task. Treat `wiki/project/Safety.md` as the authority for actions that
can affect a character or inventory.

For any `.lic` implementation, Lich API, XML state, container tracking, or
frontend/proxy boundary work, read `wiki/lich/Lich-Authoring-References.md`
before editing.

Update the relevant public wiki page when an interface, safety contract, or
verified implementation behavior changes. Use synthetic test observations.
Character records, build notes, personal routines, local settings, credentials,
and raw logs belong in private storage outside this repository.

Keep requested work bounded. Explain the reason and impact of a proposed scope
increase to the maintainer and obtain agreement before implementing it.
