## Evidence handling

Link the source, retain revision/time where available, and summarize only the
relevant evidence. Keep quotations brief. Store independent synthetic or
sanitized fixtures in tests, not raw player transcripts.

Private character knowledge and instructions belong outside the public checkout.
A public-source reference does not authorize gameplay actions.
