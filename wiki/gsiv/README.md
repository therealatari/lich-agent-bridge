# Game reference knowledge

LAB can consult the user's optional local GSWiki mirror and configured live
fallback. The public repository does not bundle player character records or
an authoritative copy of current game mechanics.

Use [GSWiki](https://gswiki.play.net/) as a reference source and retain page URL,
revision, and retrieval time when available. Verify consequential claims against
the actual source passage. A spell name or old version's page does not establish
current mechanics, and missing formulas must remain unknown.

[Item identity](Items-and-Descriptions.md) describes a generic evidence boundary.
For ingestion and privacy, see [Context system](../project/Context-System.md)
and [Sources](../reference/README.md).
