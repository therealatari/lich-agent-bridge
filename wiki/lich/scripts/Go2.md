# Go2 integration

Go2 is the maintained Lich navigation script. LAB's registered adapter accepts
a validated numeric destination rather than arbitrary script text.

Movement requires appropriate authority, current identity, and ownership.
Watch the operation and verify the resulting room; sending the navigation
command does not prove arrival. A stopped or failed trip must report where
control actually ended.

Room identifiers should come from the current map/state source, not a remembered
private route. Personal destinations and transport equipment are not bundled.
