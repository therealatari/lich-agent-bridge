# Ewaggle integration

Ewaggle is an external Lich spell-up script. Inspect its installed help, source,
and saved configuration before integrating it.

Assign one owner for each maintained buff set. Different scripts independently
attempting upkeep can create redundant work and obscure why a rest phase is
waiting. A completed script invocation is not proof every requested effect is
active; inspect structured spell state.

No character spell-up configuration is bundled with LAB.
