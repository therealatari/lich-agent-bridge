# EBounty integration

Consult [EBounty documentation](https://gswiki.play.net/Lich:Script_Ebounty)
and the installed source for supported task configuration and orchestration.

Identify the task owner, hunting owner, task-completion evidence, and return
handoff before combining automation. Accepted bounty types and character
policies remain private configuration.

Do not generalize an inventory bug in another script into EBounty without a
reproduction at its own call site. Use
[Lich's source contract](../Lich-Authoring-References.md) and an isolated test
before adding unconditional inventory refreshes.
